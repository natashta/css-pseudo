Псевдоклассы и псевдоэлементы

🔹 Псевдоклассы

Псевдокласс — это ключевое слово, которое добавляется к селектору и позволяет выбрать элемент в зависимости от его состояния, положения или других условий.

Синтаксис

селектор:pseudo-class { свойство: значение; }

Состояние элемента

:hover

Когда курсор находится над элементом.

button:hover { background: blue; }
:active

Когда элемент нажат.

button:active { transform: scale(.95); }
:focus

Когда элемент получил фокус.

input:focus { border-color: blue; }
:visited

Ссылка, которую пользователь уже посещал.

a:visited { color: purple; }
:link

Непосещённая ссылка.

a:link { color: blue; }
:disabled

Отключённый элемент формы.

button:disabled { opacity: .5; }

Выбор элементов по положению

:first-child

Первый дочерний элемент.

li:first-child { color: red; }
:last-child

Последний дочерний элемент.

li:last-child { color: red; }
:nth-child()

Элемент с определённым номером.

li:nth-child(2) { color: blue; }
:nth-child(odd)

Нечётные элементы.

li:nth-child(odd) { background: #eee; }
:nth-child(even)

Чётные элементы.

li:nth-child(even) { background: #eee; }
:not()

Все элементы, кроме указанных.

p:not(.important) { color: gray; }

🔸 Псевдоэлементы

Псевдоэлемент позволяет стилизовать определённую часть элемента или создать виртуальный элемент, которого нет непосредственно в HTML.

Синтаксис

селектор::pseudo-element { свойство: значение; }
::before

Добавляет виртуальный элемент перед содержимым.

.title::before { content: "★"; }
::after

Добавляет виртуальный элемент после содержимого.

.title::after { content: ""; display: block; height: 3px; }
::first-letter

Стилизует первую букву текста.

p::first-letter { font-size: 2em; }
::first-line

Стилизует первую строку текста.

p::first-line { font-weight: bold; }
::selection

Стилизует текст, который пользователь выделил.

::selection { background: yellow; }
::placeholder

Стилизует placeholder поля ввода.

input::placeholder { color: gray; }

⚡ Главное отличие

:

Псевдокласс

Псевдокласс описывает состояние, положение или условие выбора элемента.

:hover :focus :first-child
  • :hover — курсор наведен на элемент.
  • :focus — элемент находится в фокусе.
  • :first-child — элемент является первым дочерним.
::

Псевдоэлемент

Псевдоэлемент позволяет обратиться к определённой части элемента или создать виртуальный элемент.

::before ::after ::first-letter
  • ::before — добавляет содержимое перед содержимым элемента.
  • ::after — добавляет содержимое после содержимого элемента.
  • ::first-letter — стилизует первую букву текста.

🎯 Псевдоклассы в действии

Наведи курсор, нажми на кнопку или выбери элемент. Справа подсветится CSS-код, который отвечает за соответствующее состояние.

Демонстрация

:hover
:active

💡 Удерживай кнопку мыши — состояние :active будет видно одновременно с подсветкой кода.

:focus
:visited Открыть ссылку
:disabled
:first-child / :nth-child() / :last-child
  • Первый элемент
  • Второй элемент
  • Третий элемент
  • Последний элемент
Выбери элемент, чтобы увидеть соответствующий CSS-код.

CSS-код

button:hover {
  background: #4338ca;
}
button:active {
  transform: scale(.95);
  background: #312e81;
}
input:focus {
  border-color: #6366f1;
  box-shadow: 0 0 0 3px #e0e7ff;
}
a:visited {
  color: #7c3aed;
}
button:disabled {
  opacity: .5;
}
li:first-child {
  color: #16a34a;
}
li:nth-child(2) {
  color: #2563eb;
}
li:last-child {
  color: #dc2626;
}
